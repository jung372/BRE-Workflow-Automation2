# 풍력대동여지도 구현 검증 기록

확인일: 2026-11-12 (KST). 기준 설계: 사용자 제공 풍력대동여지도_PRD_SSD_v1.0 및 [구현 계획](PLAN-wind-map.md).

## 결과와 범위

코드 구현과 로컬 회귀검증을 완료했다. 첫 전국 운영 데이터 발행은 아직 완료하지 않았다. 독립 작업 폴더 D:/05 AI Study/BRE_Wind_Map_source, 브랜치 codex/wind-map에서 작업했다. 실제 운영 상태 파일·서비스·예약 작업은 변경하지 않았고 원격 push·배포·Teams 전송은 하지 않았다.

| 검증 | 실제 결과 |
| --- | --- |
| Python 전체 회귀 | 409개 통과, 60.538초, Windows Python 3.12 |
| 새 풍력 Python 시험 | 전체 회귀에 포함된 81개 |
| Node 프런트엔드 시험 | 기존 뉴스와 신규 풍력 합계 37개 통과, 신규 17개 |
| Python 컴파일·JavaScript 구문 | 통과 |
| PowerShell 수집 진입점 | 구문 분석 통과, UTF-8 BOM 확인 |
| Git 변경 공백 검사 | 통과 |
| 실제 Git 동시 발행 | 임시 로컬 bare 저장소에서 경쟁 push, fetch/rebase 재검증, 경로 제한 확인 |
| 백업·복원 | 임시 DB와 원본 bundle 복원, 해시 변조 거부 확인 |
| 브라우저 | 합성 자료로 데스크톱·390px 모바일 조회, 검색, 상세, 근거, 닫기·지역 복귀 확인 |

시험 명령은 [실행 안내](../wind_map/README.md)에 있다. 전체 unittest 로그의 키워드 검증 FAIL 문구는 의도된 음성 사례 출력이며 최종 결과는 OK다. 시험은 운영 DB 대신 임시 디렉터리, 저장 HTML/PDF 표본, mock, 합성 데이터를 사용했다.

## 실제 원본 PDF 확인

[전기위원회 공식 게시물](https://www.korec.go.kr/notice/moveNoticeDetail.do?bbsSntncNo=509&bbsSe=0)의 2026년 3분기 3MW 초과 발전사업허가대장을 내려받아 **864쪽 전체**를 추출했다.

- 파일 크기: 3,520,289 bytes
- SHA-256: b1bc0d9aedf74f60ab01d8632e24c2b170a2dc0ac856bfa48e976d37d53f7d85
- 원본 확인 시각: 2026-11-11T22:14:25+00:00 (파일 다운로드 시각 기준, 감사 기록으로 정정)
- 자동 페이지 상태: extracted 856쪽, needs_review 8쪽. 이는 사람의 전수 검토 완료 표시가 아니다.
- 행 분류: 머리글 868, 공란 107, 대상외 3,182, 후보 15, 검토대기 2,310. 합계 6,482행.
- 검토대기 행 또는 페이지 문제가 있는 면: 824쪽. 승인된 페이지는 0쪽이다.
- 실제 자료로 확정된 사업·허가·사건은 아직 없다. 검토되지 않은 원행에서 전국 MW나 사업 수를 발표하지 않는다.

805쪽과 860쪽은 렌더링 이미지도 직접 대조했다. 805쪽 시루풍력 항목의 60MW, 허가일 2026-05-13, 공사계획인가기간 2027-12-31, 준비기간 2029-12-31을 확인했다. **기간 만료일을 실제 공사계획인가일로 바꾸지 않는다.** 페이지 상단 좌표는 앞선 항목의 연속행이므로 시루풍력 좌표로 귀속하지 않는다. 860쪽은 이미지상 공란 표다.

3·4쪽 옛 양식의 98,000kW와 4만kW, 연도 머리글, 월 단위 날짜도 회귀 표본에 포함했다. [표본과 출처](../tests/fixtures/wind_map/provenance.json)는 저장소에 있고 전체 PDF·실제 SQLite는 Git 제외된 비공개 작업 디렉터리에 있다.

실제 자료에 운영 build를 시도한 결과 페이지 검토, 미분류 행, 서명된 정답 표본·원행 대사, 수집 coverage 누락으로 차단되는 것을 확인했다. 이 차단은 해제하지 않았다.

## 핵심 회귀 범위

- 정수 W 환산·오버플로·부동소수점 거부, 시도/시군구/미배분 합계와 허가 중복 제거.
- 효력일과 알려진 시점, 최초 허가와 현 용량 근거, 미확정 날짜, 정정 계보, 취소 이후 과거 관측의 부활 방지, 만료의 검토대기 처리.
- 분할·합병 전후 용량 보존, 명칭만 같은 사업의 자동 병합 금지.
- 인가와 기간의 분리, 환경평가 유형·단계, 설비/회차별 검사 용량 중복 제거.
- 좌표축·CRS·국내 범위·사업장 위치·선택적 GeoJSON 경계.
- 영속 큐 lease, 페이지 반복·중복·전체 건수 대사, 차단과 0건 구분, 재실행과 재조회 이력.
- 검토 digest·원본 hash 변경 시 발행 승인 무효화, 공개 필드 제한, 비공개 근거 제외.
- 파일 해시와 버전 일치, 이전 정상본 복구, 손상된 현재본에서 포인터 복구, 실제 제공 URL 검증의 mock 시험.
- Windows Git 줄바꿈 변환으로 발생한 해시 오류를 재현하고 공개 JSON -text 및 발행 명령의 LF 설정으로 해결.

## 화면 검증과 남은 운영 조건

브라우저 미리보기는 **경주시루풍력 (검증용)** 합성 사업을 쓴다. 실제 전국 데이터가 아니다. 지역 선택 → 상세 → 근거 확인 → 닫기 시 지역 복귀, 전역 검색, 모바일 상세 배경 비활성화와 스크롤 잠금, 포커스 복귀 후 첫 클릭을 확인했다.

운영 전 다음 작업이 남아 있다.

1. 실제 대장 2,310개 검토대기 행과 전 페이지를 대조하고 사업·허가·공개 근거를 확정한다. 현재 hash/digest에 연결된 정답 표본과 원행 대사를 승인한다.
2. EIASS 세 평가유형, 정보공개포털, 지자체별 실제 응답·선택자·기간·페이지 대사를 확인하고 전국 coverage를 채운다. 이번에는 KOREC 게시판과 대장 원본을 확인했으며 전국 실수집을 실행하지 않았다.
3. 카카오 지도 연결은 2026-11-13 로컬 검증을 통과했다. 도메인 등록 후 http://127.0.0.1:8876 및 http://localhost:8876의 공식 SDK 응답이 모두 HTTP 200으로 바뀌었다. 브라우저에서 실제 지도 타일, 확대(12→11), 드래그 이동, URL 위치 저장 및 상세 열기·닫기 후 위치 복원을 확인했다. 기존 키 입력 시 JSON 항목명/값 위치 오류는 수정했다. 합성 예시 사업은 좌표 미확정이므로 핀을 추가하지 않았으며 마커·클러스터 실제 조작, 모바일 실지도, 운영 도메인 검증은 남아 있다.
4. 필요한 문서에 대해 실제 Tesseract OCR 및 바이너리 HWP 변환을 확인한다. 현재 OCR 도구 미설치 처리는 시험했으나 실제 OCR 실행은 하지 않았다.
5. 전용 운영 런타임·발행 clone·예약 작업을 준비한 뒤 첫 운영 snapshot, Pages 제공 바이트, 백업 복원 절차를 운영 환경에서 검증한다.

따라서 이 기록은 코드 및 로컬 시험 완료의 근거이며 전국 데이터 정확성, 지도 SDK 실연동, 운영 서비스 개통의 완료 증명이 아니다.
