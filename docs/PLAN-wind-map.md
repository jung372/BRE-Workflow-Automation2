# 풍력대동여지도 구현 계약

기준: PRD/SSD v1.0, BRE main 9296b5e (2026-11-12). 운영 반영은 별도 단계다.

## 책임과 데이터 흐름
기관별 자료 → 불변 원본 및 페이지/행 기록 → 검토된 사업/허가 연결 → 효력일·확인일 기준 사건 계산 → SQLite 지역 집계 → 공개 허용 필드만 가진 불변 JSON → GitHub Pages.

- `wind_map`은 기존 공지와 뉴스의 DB·상태를 공유하지 않는다. 기본 런타임은 `BRE_RUNTIME_DIR/wind-map`, 명시한 `--runtime`으로 격리할 수 있다.
- SQLite WAL, FK, busy timeout과 단일 writer 트랜잭션을 사용한다. 원본은 SHA-256 주소로 보존한다. 파서는 페이지 단위의 소량 레코드를 다루며 집계는 정수 SQL/파이썬으로 처리한다. 큰 중간 DataFrame을 만들지 않는다.
- 원문 관측과 처분 사건은 별개다. 자동 추출은 후보만 생성한다. 검토자가 승인한 근거에 한해서 사건·좌표·지역 배분을 채택한다.
- 용량은 정수 W. 효력일과 확인일을 모두 조회 조건으로 적용한다. 정정·취소·분할·통합 관계를 보존하고 같은 효력일의 충돌은 보류한다.
- 월/연도/범위 날짜는 정밀도를 보존한다. 완료 일자 미확인과 미완료, 자료 없음과 0을 구별한다.
- 전국 검색은 영속 대기열, 페이지 fingerprint, 건수 대사, 날짜 구간 분할, 재시도로 구성한다. 접근 제한·반복 페이지를 정상 완료로 기록하지 않는다.
- PDF 미처리 페이지, 미분류 행, 검토 미완료, 공개되지 않은 확정 근거, 배분 불일치, 정답 표본 미승인은 실제 snapshot 생성을 차단한다. 합성 예시는 preview에만 허용한다.
- 공개 JSON은 명시적인 허용 필드와 URL 검증을 사용한다. 원문 원본, 개인정보, 내부 메모, 제한 회신은 공개 디렉터리로 복사하지 않는다.
- 허용 필터는 유효 EBL/유효성 확인 중/심의 가결 후 허가 미확인/취소/전체와 지역이다. 각 집계는 서버에서 생성한다. 검색은 사업 선택 기능이며 집계 필터와 구별한다.
- 전용 발행 clone과 wind-map 경로 허용 목록을 사용한다. 기존 Windows/WSL 발행기와 OS 파일 락의 호환을 가정하지 않고 push 충돌 시 최신 원격 위로 rebase하고 바이트·합계를 재검증한 뒤 제한적으로 재시도한다. 같은 자료의 충돌은 중단하고 검토한다. 공유 clone과 강제 push는 사용하지 않는다.
- manifest와 파일 hash/snapshot_id를 검증하고 버전이 섞이면 이전 정상본으로 복귀한다. 공개 JSON 변경은 코드 배포와 분리하되 데이터 검증 CI는 유지한다.

## 대안과 영향
기존 state.py 확장은 짧은 스냅샷 보존 및 100건 제한 때문에 제외한다. 기존 뉴스 DB 확장은 도메인과 writer 경계를 섞으므로 제외한다. 신규 API 서버 대신 정적 snapshot을 유지하고, 내부 검토는 파일/CLI 기반으로 시작한다. React·별도 상주 서비스는 도입하지 않는다.

## 검증과 복구
임시 SQLite·로컬 HTTP/Git fixture로 중복 적재, 재개, 정정·취소, 지역 배분, 공개 필드, 발행 충돌·중단을 검사한다. 기존 unittest와 Node 회귀, 실제 PDF 표본 대조, 브라우저 대체 화면을 확인한다. DB 백업은 SQLite backup API로 생성하고 integrity_check 후 복원한다. 코드 rollback과 DB schema downgrade는 별개이며 기존 DB를 덮어쓰지 않는다. 공개 pointer는 이전 정상 version으로 복원할 수 있다.

## 서버 배포 범위 (2026-11-13)

이번 배포는 검증된 코드와 지도 탭을 기존 GitHub Pages 및 Windows 릴리스에 반영한다. 릴리스 환경에는 wind_map/requirements.txt를 설치하고, 비공개 작업 원본과 개발 가상환경은 릴리스 복사 대상에서 제외한다. 실제 원본·DB는 BRE_Workflow_runtime/wind-map으로 분리하고 SQLite backup-bundle/restore-bundle 절차로 이전·검증한다. 코드 롤백은 기존 current_release.txt의 직전 릴리스로 복원하며 DB를 되돌리지 않는다.

미검토 전국 자료와 합성 미리보기를 공개하지 않는다. 공개 화면은 첫 검증본 생성 전까지 준비 중 상태를 제공한다. EIASS·지자체 수집 설정과 전국 검산이 완료되지 않았으므로 이번 배포에서 전국 수집 예약 작업이나 자동 발행 작업을 만들지 않는다. 기존 공지·풍력/태양광 뉴스 일정 및 Teams 설정은 유지한다. 후속 공개 데이터 발행은 기존 발행 gate와 전용 clone 계약을 따른다.
