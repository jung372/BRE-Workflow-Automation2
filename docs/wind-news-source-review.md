# 일반 언론 뉴스 수집 서비스 검토

## 2026-10-01 수집 범위 확장

특정 3개 매체의 목록만으로는 산업 전반을 다룰 수 없다는 사용자 피드백에 따라 네이버 공개 뉴스 검색을 기사 링크 발견 경로로 추가했다. 풍력 일반·육상/해상/부유식·인허가·입찰·PF·주민 수용성·해저케이블·모노파일·터빈·설치선·풍황과 기업·프로젝트명을 포함한 24개 검색을 순회한다. 검색 결과의 실제 다음 페이지 주소를 따르며, 단순 `start` 증가로 첫 페이지를 반복하는 방식은 사용하지 않는다.

검색 결과의 요약문·검색 시각은 AI 근거로 사용하지 않는다. 언론사 원문의 본문·제목·발행시각·매체명을 추출한다. 기존 3개 매체의 보조 수집도 유지한다. 네이버 검색 API 키는 사용하지 않는다. 구글 검색은 이번 HTTP 시험에서 기사 결과 대신 JavaScript 안내만 반환했으므로 실제 운영 수집 경로로 포함하지 않았다.

검색별 페이지 제한과 본문 요청 제한은 설정으로 관리하며, 발견·시도·성공·무관·유료/접근 제한·파싱 오류 건수를 구분해 저장한다. 알려진 매체 3곳만 허용하는 제약을 제거하되 모든 원문 및 리다이렉트는 HTTPS·공개 IP 여부를 검증한다. 로그인/결제 우회나 인증서 검증 해제는 하지 않는다. 기사 본문 안에 풍력 단어가 없더라도 모노파일·풍황·해상변전소 또는 관련 공급망 문맥으로 산업 연관성을 판정한다.

아래의 9월 30일 3개 매체 운영 방침은 확장 전 이력이다.

확인일: 2026-09-30. 국내 풍력, 일반 언론 기사 포함, 구독·결제 필요 기사 제외가 사용자 확정 범위다. 공공기관 보도자료만으로 범위를 축소하지 않는다. 아직 공급 계약·유료 API 가입·문의 전송은 하지 않았다.

## 사용자 확정 운영 방침 — 2026-09-30 후속 지시

별도 언론사 계약·공급사 문의·유료 API 가입을 선행 조건으로 두지 않고 공개 기사 추출을 진행한다. 외부 서비스의 유료/무료 식별값은 요구하지 않는다. 연합뉴스 RSS와 전기신문·에너지신문의 공개 목록에서 원문을 찾아 일반 HTTP 요청으로 읽을 수 있는 기사 본문을 사용한다. 로그인·결제 제한 안내 또는 불완전한 본문은 제외하고, 출처명과 원문 링크를 공개 브리핑에 표시한다.

`require_rights_review=false`는 위 사용자 운영 방침을 반영한 설정이다. 출처의 `rights_reviewed`를 허위로 완료 처리하지 않고 `authorization_basis`에 사용자 지시를 기록한다. 실제 원문 접근 여부는 `access_basis=public_article_body`와 확인 시각으로 남긴다. 원문 근거는 기존 30일 보존 정책, 발간 요약·메타데이터·호는 장기 보존 정책을 유지한다.

아래 공급사 검토와 문의 초안은 과거 검토 기록이며, 현재 발간을 기다리게 하는 조건이 아니다. 네이버 검색 API 대신 원 매체의 공개 페이지를 사용한다.

## 공급사에 확인할 구체적 범위

다음 내용은 문의 초안이며 아직 발송하지 않았다. API 결제만으로 모든 기사에 대한 요약·재게시 권리가 부여된다고 보지 않는다.

> 국내 풍력산업의 무료 공개 언론 기사만 대상으로 일간 최대 15개 주제의 브리핑을 운영하려 합니다. 유료·구독 전용 기사는 제외합니다. 제공되는 제목·본문 또는 발췌를 OpenAI의 공식 Codex CLI로 입력해 자체 요약하고, 기사 URL·매체·발행시각·자체 요약·사건 분류를 장기 DB에 저장하여 공개 웹사이트에서 날짜별 조회 및 검색을 제공하려 합니다. 기사 원문 전체나 사진을 웹에 재배포하지 않습니다. 요약 근거 텍스트는 현재 최대 30일 보관 설정입니다.
>
> 1. 이 AI 입력·근거 보존·자체 요약 공개·메타데이터 장기 보존 범위가 허용되는지와 별도 언론사 계약이 필요한지 알려주세요.
> 2. 연합뉴스·전기신문·에너지신문 등 국내 풍력 관련 매체 제공 여부와 기사별 유료/무료 식별값을 제공하나요?
> 3. 월 기본료·최소 약정·초과요금·해지 조건·실데이터 시험 범위를 알려주세요. 발간량은 최대 15개 주제/일이며 수집 조회량은 시험 결과로 산정하겠습니다.
> 4. 출처·원문 링크 표시 형식, 삭제·정정 요청 처리 및 계약 종료 후 메타데이터·자체 요약의 보존 가능 범위를 알려주세요.

이 문의 초안은 보관만 하며 발송하지 않는다. 현재 실행 경로는 위 사용자 확정 방침에 따른 원 매체 공개 페이지 수집이다.
