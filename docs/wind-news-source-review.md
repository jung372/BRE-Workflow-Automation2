# 일반 언론 뉴스 수집 서비스 검토

확인일: 2026-09-30. 국내 풍력, 일반 언론 기사 포함, 구독·결제 필요 기사 제외가 사용자 확정 범위다. 공공기관 보도자료만으로 범위를 축소하지 않는다. 아직 공급 계약·유료 API 가입·문의 전송은 하지 않았다.

## 공급사에 확인할 구체적 범위

다음 내용은 문의 초안이며 아직 발송하지 않았다. API 결제만으로 모든 기사에 대한 요약·재게시 권리가 부여된다고 보지 않는다.

> 국내 풍력산업의 무료 공개 언론 기사만 대상으로 일간 최대 15개 주제의 브리핑을 운영하려 합니다. 유료·구독 전용 기사는 제외합니다. 제공되는 제목·본문 또는 발췌를 OpenAI의 공식 Codex CLI로 입력해 자체 요약하고, 기사 URL·매체·발행시각·자체 요약·사건 분류를 장기 DB에 저장하여 공개 웹사이트에서 날짜별 조회 및 검색을 제공하려 합니다. 기사 원문 전체나 사진을 웹에 재배포하지 않습니다. 요약 근거 텍스트는 현재 최대 30일 보관 설정입니다.
>
> 1. 이 AI 입력·근거 보존·자체 요약 공개·메타데이터 장기 보존 범위가 허용되는지와 별도 언론사 계약이 필요한지 알려주세요.
> 2. 연합뉴스·전기신문·에너지신문 등 국내 풍력 관련 매체 제공 여부와 기사별 유료/무료 식별값을 제공하나요?
> 3. 월 기본료·최소 약정·초과요금·해지 조건·실데이터 시험 범위를 알려주세요. 발간량은 최대 15개 주제/일이며 수집 조회량은 시험 결과로 산정하겠습니다.
> 4. 출처·원문 링크 표시 형식, 삭제·정정 요청 처리 및 계약 종료 후 메타데이터·자체 요약의 보존 가능 범위를 알려주세요.

조건과 견적이 확인되면 한 곳을 선정해 무료 기사 필터, 원문 근거 대조, OAuth 요약, DB 적재, 첫 호 웹 게시 순으로 검증한다. 그 전에는 수집·발간 일정을 활성화하지 않는다.
